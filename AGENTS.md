# Место SPA — тестовое задание (hh.ru, агентство «Бумеранг»)

## Контекст

Тестовое: лендинг вымышленной SPA-студии «Место SPA» (Москва). Выбор программы + заявка.
Исходные материалы: `job.txt` (вакансия), `test.txt` (задание).
Срок: 48 часов от согласия. **Декларированный бюджет работы — 3 часа** (вести учёт в `docs/04-PLAN.md`).
Отправка: одной сообщением в чат вакансии на hh.ru (ссылка на сайт + ссылка на код + заметка).

Что реально оценивают (веса): дизайн-вкус ~50%, завершённость основного сценария ~20%,
работа с AI (2 промпта + 1 правка) ~15%, production-готовность ~15%.

## Стек и инфраструктура

- **Vite + React 19 + TypeScript + Tailwind CSS v4** — единственный стек, не менять.
- Деплой: **Vercel**, репозиторий **публичный** на GitHub (через `gh`).
- Страница одна, роутинг не нужен. Backend нет. Хранилище: `localStorage`.
- UI полностью на русском языке.

## Дизайн-направление: «тёплый люкс»

Полное описание — `docs/03-DESIGN-SYSTEM.md` (согласовано). Ключевое:

- Палитра: кремовый фон `#F6F1E9`, тёплый чернильный текст `#1E1B16`, моховой акцент `#2E4636`.
  Никакого чистого серого, синего, индиго.
- Шрифты: **Cormorant Garamond** (заголовки) + **Manrope** (текст/UI), через `@fontsource`.
- Иконки: только инлайновый SVG со штрихом. **Эмодзи запрещены** в UI и в README.
- Кнопки — «пилюли», карточки — мягкие углы 20px, тени тёплые и слабые.

## Анти-slop правила (проверять себя)

Запрещено (явные признаки «сделано ИИ», ловятся сканером `kill-ai-slop`):

1. Индиго/фиолетовые градиенты, gradient-clip на заголовках, glow/glassmorphism-карточки.
2. Эмодзи как иконки, ALL-CAPS стат-карточки, «скролль-репили» из шаблонов.
3. Дефолтный look: 4 одинаковые карточки без иерархии, радиус и тень везде одинаковые.
4. Чужие шаблоны целиком (задание прямо запрещает).

Перед финальной сдачей: прогнать `node .opencode/skills/kill-ai-slop/scripts/scan.mjs . --exclude=.opencode --exclude=docs --rules=.opencode/skills/kill-ai-slop/scripts/rules.ru.mjs` → 0 hits.

## Качество — не заявлять «готово» без проверок

Перед каждым «готово» прогнать чеклист `docs/05-QA-CHECKLIST.md` через **Playwright MCP**:
скриншоты 360 и 1440px, отсутствие горизонтального скролла (`scrollWidth <= innerWidth`),
прокликивание всех ошибок формы, перезагрузка страницы (localStorage), контраст, приватное окно.

## Работа с AI — журнал обязателен

`docs/06-AI-WORKFLOW.md` пополнять по ходу: 2 лучших промпта + 1 реальная правка ошибки.
Это напрямую уходит в ответ работодателю — писать честно, по-русски, коротко.

## Скиллы (`.opencode/skills/`, загружаются opencode)

- `design-taste-frontend` — анти-slop арт-дирекшн, подключать при генерации любого UI.
- `kill-ai-slop` — сканер/вычистка tells перед сдачей.
- `apple-design` — отклики, типографика (трекинг/интерлиньяж), reduced-motion.
- `beautify-github-readme` — финальный README репозитория.
