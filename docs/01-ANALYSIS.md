# 01. Разбор задания

## Что просит

Одностраничный сайт вымышленной SPA-студии «Место SPA» (Москва):
первый экран с предложением → три карточки программ → форма заявки → подтверждение.

## Программы (данные из задания, менять нельзя)

| Программа | Длительность | Цена |
|---|---|---|
| Перезагрузка | 60 минут | 3 500 ₽ |
| Глубокий отдых | 90 минут | 5 000 ₽ |
| Для двоих | 120 минут | 9 000 ₽ |

## Обязательные пункты (чек-лист требований)

1. Адаптивная страница, первый экран с понятным предложением, 3 карточки, заметная кнопка заявки.
2. Дизайн **наш**; готовые компоненты можно, чужой шаблон целиком — нельзя.
3. Форма: имя, программа (подставляется из карточки), желаемая дата.
4. Ошибки: пустые поля и прошедшая дата — понятные сообщения.
5. После отправки — подтверждение с деталями заявки.
6. Заявка в `localStorage`, переживает обновление страницы.
7. Опубликовать по доступной ссылке; проверить на 360 и 1440 px: читаемость, нет горизонтальной прокрутки, форма работает.
8. Отчёт: 2 примера запросов к AI + что получили; 1 конкретная правка ошибки (что было не так, как заметили, что изменили); какой AI, сколько времени, известные недоработки.
9. Отправить одним сообщением в чат вакансии: ссылка на сайт (проверить в приватном окне) + ссылка на код + короткая заметка.
10. Перед началом — согласие в чате (уже дано).

## Чего НЕ нужно (ловушка — не делать!)

Backend, авторизация, оплата, CRM, реальная запись, карта, галерея, блог, тёмная тема,
дополнительные экраны. Задание прямо: *«Дополнительные экраны и сложные функции не дают
преимущества сами по себе. Лучше завершить основной сценарий и аккуратно оформить страницу.»*

## Что на самом деле проверяют

| Критерий | Как проявится в работе | Вес |
|---|---|---|
| Дизайн-вкус | «Тексты, цвета, шрифты и изображения выберите сами» = свобода = чистый тест вкуса | ~50% |
| Завершённость сценария | Карточка → подстановка → валидация → подтверждение → persistence, без «незавершённого» | ~20% |
| Работа с AI | 2 промпта + 1 правка: видно, ставишь ли ты задачи и проверяешь ли результат | ~15% |
| Production | Ссылка живёт, 360/1440 ок, приватное окно, README, честные недоработки | ~15% |

## Как проигрывают другие кандидаты (типичные ошибки)

1. «AI-лук» по умолчанию: фиолетовые градиенты, эмодзи-иконки, одинаковые карточки с glow-тенью.
2. Валидация только `required` из браузера — прошедшая дата не проверяется, текстов ошибок нет.
3. Подтверждение — голое «Спасибо!» без деталей заявки.
4. На 360px горизонтальный скролл, кнопки «в край», текст режется.
5. Промпты к AI выдуманные или ванильные («сделай красиво») — видно, что не умели ставить задачу.
6. Фича-кринж вместо полировки: карта, слайдер, тёмная тема — и убитое время на основное.

## Особенности и замечания к ТЗ (зафиксировано при QA)

- **Нет поля телефона.** ТЗ прямо задаёт состав формы: имя, программа, дата — без телефона.
  Поле не добавляли (лишние элементы против ТЗ). Зато копирайтинг страницы не обещает
  канал связи, которого нет: вместо «перезвоним / по телефону» — «подтвердим время в течение часа».
  Ограничение учебного проекта без backend отражено дисклеймером в футере.
