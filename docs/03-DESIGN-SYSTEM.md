# 03. Дизайн-система: «тёплый люкс»

Согласованное направление (выбор A). Ссылки для генерации UI: скилл
`.opencode/skills/design-taste-frontend/SKILL.md` — арт-дирекшн и анти-slop правила;
настоящий документ — источник конкретных значений.

## Идея

SPA = остановиться, выдохнуть, почувствовать тепло. Сайт должен ощущаться как
мягкая бумага и чай: **тёплый кремовый фон, глубокий зелёный «мх», тихая типографика,
много воздуха**. Никакого «стартапного» неона и холода.

## Цвета

| Роль | HEX | Где |
|---|---|---|
| Фон (бумага) | `#F6F1E9` | body |
| Поверхность (карточки, форма) | `#FBF8F3` | карточки, поля |
| Чернила (текст) | `#1E1B16` | заголовки, body |
| Чернила вторичные | `#5F594E` | подписи, описания |
| Мох (акцент, primary) | `#2E4636` | кнопки, бейдж, фокус, иконки |
| Мох hover | `#3A5A45` | hover primary |
| Линии/бордеры | `#E4DCCF` | инпуты, разделители, hairline |
| Тёплая глина (микро-акцент) | `#B4633F` | бейдж цены/«подарок» — только точечно |
| Ошибка | `#A33A2A` | текст и бордер ошибки (тёплый красный, не pure red) |
| Успех | `#3E6B4F` | галочка подтверждения |

Контраст: `#1E1B16` на `#F6F1E9` ≈ 15:1 (AAA). Кремовый текст на мохе ≈ 9:1 (AA+).
Никакого чистого `#000/#fff/#888/синего/индиго`.

## Типографика

- **Заголовки:** Cormorant Garamond (500/600) — через `@fontsource/cormorant-garamond`.
- **Текст/UI:** Manrope (400/500/600/700) — через `@fontsource-variable/manrope`.

| Утилита | Размер | Line-height | Трекинг |
|---|---|---|---|
| Hero H1 | `clamp(2.5rem, 6vw, 4.25rem)` | 1.05 | -0.01em |
| H2 секций | `clamp(1.9rem, 4vw, 2.75rem)` | 1.1 | -0.005em |
| H3/карточка | 1.375–1.5rem | 1.25 | 0 |
| Body | 1rem–1.0625rem | 1.6 | 0 |
| Подпись/лейбл (uppercase) | 0.75rem, Manrope 600 | 1.4 | +0.12em |

Приёмы: цифры цен — Manrope 700 tabular; «₽» чуть меньше номинала; длинное тире в копирайте.

## Сетка и отступы

- Контейнер: `max-width: 1200px`, горизонтальные отступы 20px (моб.) / 32px (десктоп).
- Секции: вертикальные отступы `clamp(64px, 10vw, 120px)`.
- Шкала отступов — стандартная Tailwind (4/8/12/16/20/24/32/40/48/64/80/96).
- Брейкпоинты: `sm 640, md 768, lg 1024, xl 1280` (Tailwind). Проверять **360** и **1440**.

## Формы и скругления

- Кнопки — «пилюли» (`border-radius: 9999px`), высота ≥ 44px (тач-таргеты).
- Карточки/панели — `20px`, поля — `12px`.
- Тени (тёплые, слабые):
  - карточка: `0 1px 2px rgba(30,27,22,.04), 0 16px 40px -20px rgba(30,27,22,.18)`
  - hover: чуть глубже + `translateY(-3px)`.
- Никакого glow, glassmorphism (запрещено анти-slop правилами).

## Компоненты

**Кнопка primary:** заливка мох, текст `#F6F1E9`, Manrope 600, pill, hover `#3A5A45`,
active `scale(.98)`, focus-visible — кольцо `2px #2E4636` с офсетом.
**Кнопка ghost:** прозрачная, бордер `1px #1E1B16`, hover — фон `rgba(30,27,22,.06)`.

**Карточка программы:** поверхность `#FBF8F3`, radius 20, паддинг 28–32; сверху —
SVG-штрихикон (64px, stroke 1.5, color мох); название (Cormorant 600, 1.5rem);
длительность — подпись uppercase; описание — вторичный текст; цена — Manrope 700, 1.5rem;
кнопка «Выбрать программу» (primary, full-width на мобиле).
**Акцентная карточка** (Глубокий отдых): бордер `1.5px #2E4636` + бейдж-пилюля на каждой
карточке: «Сброс за час» · «Выбор гостей» · «Вдвоём теплее» (на мобиле — по центру)
(мох, pill, uppercase-label) — иерархия без крика.

**Поле формы:** фон `#F6F1E9` (или `#FFFDF9`), бордер `1px #E4DCCF`, radius 12,
padding 12/16; focus: бордер мох + кольцо `rgba(46,70,54,.15)`;
ошибка: бордер `#A33A2A` + текст под полем (Manrope 500, .875rem, `#A33A2A`) с SVG-восклицанием.

**Подтверждение:** карточка с круглой галочкой (SVG, `#3E6B4F`), заголовок «Заявка принята»,
список деталей (имя / программа / длительность / цена / дата «14.06.2026» / номер `SPA-2074`),
кнопка «Оформить ещё одну заявку».

## Иконки и изображения

- Иконки — только inline SVG, штрих 1.5, `currentColor`. Эмодзи запрещены.
- Фото — тёплые (пар, свет, камень, дерево): скачивать из Unsplash в `public/img/`
  (локально, без внешних хотлинков). Ставить с `loading="lazy"`, alt по-русски,
  и обязательно `object-fit: cover` с мягкой градиентной виньеткой под текст.

## Движение

- Длительности 150–300ms, `cubic-bezier(.2,.6,.2,1)`.
- Hover карточки: `translateY(-3px)` + тень; кнопки: фон + `scale(.98)` на active
  (отклик на pointer-down — принцип apple-design).
- Скролл к форме: `scroll-behavior: smooth` + `scroll-margin-top` под sticky-хедер.
- Всё под `@media (prefers-reduced-motion: reduce)` — отключать трансформации, оставить opacity.

## Структура страницы (ровно 5 блоков)

1. **Хедер** — логотип-вордмарк «Место SPA» (Cormorant), якоря «Программы» и «Заявка»,
   pill-кнопка «Оставить заявку». Фиксируется, непрозрачный кремовый + hairline снизу.
2. **Hero** — крупный H1, подзаголовок, primary CTA «Выбрать программу», фото справа/фоном.
3. **Программы** — H2 + 3 карточки (+ строка «почему мы» из 3 пунктов ниже — компактно).
4. **Форма заявки** — `id="application"`, 3 поля, ошибки, состояние успеха.
5. **Футер** — вымышленные контакты + честная оговорка «Учебный проект, заявки не отправляются».

## Copy (черновик, утвердить при сборке)

- H1: **«Отдохните по-настоящему — за один вечер»**
- Sub: «Три авторские SPA-программы в центре Москвы. Выберите подходящую и оставьте
  заявку — подтвердим время в течение часа.»
  (по ТЗ в форме нет телефона — не обещать «перезвоним»/«по телефону»)
- H2 программ: «Три способа восстановиться»
- CTA: «Выбрать программу» / подпись: «Заявка занимает меньше минуты»
- Описания карт:
  - Перезагрузка: «Быстрый сброс: хаммам, контрастный бассейн и расслабляющий массаж спины.»
  - Глубокий отдых: «Полный ритуал: сауна, пилинг, массаж всего тела и чайная пауза.»
  - Для двоих: «Совместный отдых: парная для двоих, массаж и закуски в приватной комнате.»
- «Почему мы»: «5 минут от метро» · «Чай после каждой процедуры» · «Приватные зоны»
- Ошибки: «Введите имя» · «Выберите программу» · «Выберите дату» ·
  «Дата не может быть в прошлом» · «Имя — минимум 2 символа»
