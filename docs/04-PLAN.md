## Фазы

- `npm create vite@latest` (react-ts), Tailwind v4, `@fontsource` (Cormorant Garamond, Manrope Variable).
- Структура `src/`: `App.tsx`, `components/{Header,Hero,Programs,ApplicationForm,Footer}.tsx`,
  `data/programs.ts`, `lib/{storage.ts,validation.ts}`.
- Ставим токены дизайн-системы в `src/index.css` (`@theme` Tailwind v4).

### Ф1. Шелл + Hero — 0:15 → 0:45

### Ф2. Карточки программ — 0:45 → 1:15

- Строка «Почему мы» (3 пункта). Кнопка «Выбрать программу» на карточке.

### Ф3. Форма и валидация — 1:15 → 1:50
- Поля: имя, программа (select), дата (`min` = сегодня).
- Инлайн-ошибки (4 сценария из ТЗ), подстановка программы при клике на карточку
  (скролл + подсветка выбранного), disabled/aria-state кнопки.

### Ф4. Подтверждение + localStorage — 1:50 → 2:10
- Успех-состояние с деталями (номер, цена, дата `dd.mm.yyyy`).
- Ключ `meesto-spa:applications` (массив), восстановление последней заявки после reload,
  кнопка «Оформить ещё одну».

### Ф5. QA (Playwright MCP) — 2:10 → 2:35
- Скриншоты 360 / 1440, `scrollWidth <= innerWidth`, прогон всех ошибок формы,
  reload-тест, focus-visible, контраст, reduced-motion.
- Фиксировать находки и правки → это материал для «одна проверка/правка» в отчёте.
- Сканер `kill-ai-slop` → добиваем до 0 hits.

### Ф6. Деплой + финализация — 2:35 → 2:55
- Push в GitHub, Vercel (`vercel --prod` или интеграция), ссылка в incognito.

- Заполнить `docs/06-AI-WORKFLOW.md` (2 промпта + 1 правка), `docs/05-QA-CHECKLIST.md` (галочки).
