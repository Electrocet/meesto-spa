# 05. QA-чеклист (прогнать перед каждым «готово» и перед отправкой)

Инструмент: **Playwright MCP** (браузер Chrome, изолированный профиль = приватное окно) +
сканер **kill-ai-slop**. Каждый пункт — галочка только после реальной проверки.

## A. Вёрстка и адаптив

- [x] 360px: нет горизонтального скролла — `document.documentElement.scrollWidth <= window.innerWidth`
- [x] 1440px: то же + макет не «плывёт», контейнер ≤ 1200px по центру
- [x] Скриншоты обоих ширины сохранены (см. `docs/qa/`), читаемость текста ок (нет слишком мелкого/обрезанного)
- [x] Нет переполнения по вертикали из-за абсолютно позиционированных элементов
- [x] Sticky-хедер не перекрывает якорную секцию (`scroll-margin-top`)

## B. Первый экран

- [x] H1, подзаголовок и кнопка видны без скролла на 360 и 1440
- [x] Кнопка «Выбрать программу» ≥ 44px по высоте, видна без поиска
- [x] Фото грузится (нет битой картинки), alt по-русски

## C. Карточки

- [x] Все 3 программы: название, длительность, цена из ТЗ дословно (60/3 500, 90/5 000, 120/9 000)
- [x] Средняя акцентирована (иерархия видна), не 3 одинаковые плитки
- [x] Клик «Выбрать программу» → скролл к форме + программа подставлена

## D. Форма — все 4 ошибки

- [x] Пустое имя → «Введите имя» (инлайн, не alert)
- [x] Не выбрана программа → «Выберите программу»
- [x] Пустая дата → «Выберите дату»
- [x] Вчерашняя дата → «Дата не может быть в прошлом»; **сегодняшняя — проходит**
- [x] Ошибки пропадают после исправления поля; фокус/aria-состояния корректны

## E. Отправка и подтверждение

- [x] Валидная отправка → подтверждение с: именем, программой, длительностью, ценой, датой (формат «14.06.2026»)
- [x] Есть кнопка «Оформить ещё одну заявку» (возврат к форме)

## F. localStorage

- [x] После отправки: обновить страницу (F5) → заявка восстановлена (подтверждение или явный блок)
- [x] Ключ/данные: `Application → localStorage` содержит корректный JSON (проверить в devtools/JS)
- [x] Очистка localStorage → страница работает как новая

## G. Качество визуала

- [x] Контраст: основной текст ≥ 4.5:1 (замерить JS-ом или визуально по токенам), акцент на фоне ≥ 3:1
- [x] Нет запрещённого: индиго/фиолет, glass/glow, эмодзи-иконок, ALL-CAPS стат-блоков
- [x] `kill-ai-slop` сканер → **0 hits**. Команда (исключаем сами скиллы/доки, + русские AI-клише):
  `node .opencode/skills/kill-ai-slop/scripts/scan.mjs . --exclude=.opencode --exclude=docs --rules=.opencode/skills/kill-ai-slop/scripts/rules.ru.mjs`
- [x] `prefers-reduced-motion: reduce` — анимации отключаются (проверить эмуляцией)
- [x] Focus-visible виден на всех интерактивных элементах (таб по странице)

## H. Production

- [x] Ссылка открывается в **приватном окне** без логинов и ошибок консоли (проверено на https://meesto-spa.vercel.app, изолированный профиль Playwright)
- [x] Консоли браузера нет ошибок/404 на **проде** (0 ошибок Console, hero-картинка грузится, localStorage работает)
- [x] `<title>`, description, favicon, `lang="ru"` на месте
- [x] README репозитория открывается, ссылка на сайт работает (создан и запушен, аудит скриптом скилла пройден)
